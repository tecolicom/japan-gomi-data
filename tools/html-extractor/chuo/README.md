# 中央区 (chuo) — あなたの町のごみ・資源収集曜日

```
node fetch.mjs                           # cache/ に HTML + パンフ 3 種 + ABR を揃える
EXTRACTED_AT=2026-09-15 node build.mjs   # course-*.yaml を生成
node verify.mjs                          # パンフとの照合 + 版どうし + 生成物
node verify.mjs --tamper                 # 検査が実際に落ちることを確かめる
```

`meta.yaml` / `taxonomy.yaml` は**生成しない**。手書きが正典。

## ソース

| | 中身 | 役割 |
|---|---|---|
| 区公式「あなたの町のごみ・資源収集曜日」HTML | 3 地域 56 行 × 5 品目 (粗大含む)。**日本語の町名があるのはここだけ** | **一次ソース** |
| 「ごみと資源の分け方・出し方」外国語版 (英・中) | 同じ曜日表 | 照合 |
| 同 日本語版 | 同じ内容 | **使えない** (27+25 ページで 54 字の画像 PDF) |
| 同 韓国語版 | 同じ表 | **使わない** (下記) |

日本語版パンフが読めず外国語版だけにテキスト層がある構図は豊島・江東と同じ。

### 韓国語版を照合から外した理由

町名のハングルに曜日と同じ字が混じり (신**토**미 / 미나**토** / 가부**토**초 の「토」= 土)、
曜日グループが 5 個でなく 6 個になる。さらに「닌교초 2초메1〜14번」の週5日の値が
行またぎで分断される。「最後の 5 個を採る」等で辻褄は合わせられるが、
**取り繕いが要る検査は検査にならない**。英語版・中国語版で独立な版は 2 つ確保できている。

## 踏んだ罠

| 罠 | 何が起きたか | 対処 |
|---|---|---|
| **`<br>` の意味が列で違う** | 曜日列の `月曜日・火曜日・水曜日<br>金曜日・土曜日` は**区切り** (`・` が落ちている)、丁目列の `1丁目1～<br>5番` は**折り返し**。一律に扱うとどちらかが壊れる | 列ごとに `<br>` → `・` / `''` を変える |
| **パンフの並びが HTML と違う** | 本文の物理的な順が 京橋 → **月島** → 日本橋。素直に上から読むと日本橋と月島が入れ替わり、**320/560 セルが食い違った** | 見出しで切り分けて地域ごとに突き合わせる |
| **rowspan が音と町名で独立** | 銀座の行は音も町名も欠け、蛎殻町2丁目は音だけ欠ける | 列ごとに繰り越す |
| **区が町名を略している** | 表の「蛎殻町」は正式には「日本橋蛎殻町」(19 町 33 行) | 素の名前で ABR を引き、無ければ「日本橋」を前置。どちらでも引けなければ止める |
| **繁華街の週6日と週5日** | 京橋等が「月曜日～土曜日」、日本橋人形町2丁目1～14番だけ「月・火・水・金・土」 | 範囲展開と並記の両方を parse。週をまたぐ範囲と日曜を含む範囲は throw |

## 検査

`build.mjs` が毎回やること。

- ABR 町字 98 件をちょうど被覆するか (「全域」の行は ABR の全丁目へ展開)
- 曜日セル 280 個がすべて読めるか (未対応の表記は `parseDays` が throw)
- 自己検証: 生成 rules の再展開が元の曜日セルと全日一致

`verify.mjs` の 3 系統。

| | 何と何を比べるか | 規模 |
|---|---|---|
| A. パンフレット | HTML ↔ 英語版 / 中国語版 | 560 セル |
| B. 版どうし | 英語版 ↔ 中国語版 | 280 セル |
| C. 生成物 | HTML+ABR から**別実装で**組んだ期待 area ↔ course YAML | 104 area / 34,736 日枠 |

**C は期待集合を build とは別に組み立てて両方向で比べる。** 最初は HTML 側から生成物を
引く片方向だったため、生成物から area を消しても残りが引けて通ってしまった
(改竄検査で空振り。江東でも同型を踏んでいる)。

`node verify.mjs --tamper` は 5 通りの改竄で各検査が落ちることを確かめる。
