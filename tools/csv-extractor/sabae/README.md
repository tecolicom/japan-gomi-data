# 鯖江市 (sabae)

福井県オープンデータの CSV から `course-*.yaml` を生成する。

| | |
|---|---|
| 一次ソース | [福井県 OD: 鯖江市ごみ収集日 CSV](https://www.pref.fukui.lg.jp/doc/dx-suishin/list_ct_gomisyusyubi_d/fil/sabaeshisyusyubi.csv) (町名 × 品目 → 収集曜日) |
| 補助ソース | 内閣府「[国民の祝日について](https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv)」CSV / エコプラザさばえ「年末年始のごみ収集」PDF |
| 収録期間 | 2026-04--2027-03 (令和8年度) |
| コース | 4 (町名 174 を (可燃の曜日, 資源の曜日) で畳む) |
| 独立照合ソース | **無い。** 日程を表す資料は県 OD の CSV だけ |

## この市の特徴 — 曜日しか書いていない

CSV には**曜日しか無い**。実日付に落とすには補助ソースが 2 つ要る。

### 1. 祝日 — 可燃は収集し、資源は休む

可燃ごみは休日も収集する。資源系 (不燃・びん・缶・ペット・プラ・紙布・有害) は
祝日は収集しない。祝日は内閣府の公式 CSV から取る (推測で作らない)。

**可燃と資源の曜日が重なるコースは存在しない**ので、休止は `cancelled: true`
(その日は全休止) で表せている。将来重なったら `cancelled` では資源だけを止められないので、
build が throw する。

### 2. 年末年始 — 一律の期間では表せない

**品目別・曜日別に最終日と開始日が違う。** 「12/29〜1/3 休止」のような書き方はできない。

| | 年末最終日 | 年始開始日 |
|---|---|---|
| 燃やすごみ 月・木 | 12/28 (月) | 1/4 (月) |
| 燃やすごみ 火・金 | 12/29 (火) | 1/5 (火) |
| 資源 火 | 12/22 (火) | 1/5 (火) |
| 資源 水 | 12/23 (水) | 1/6 (水) |
| 資源 木 | 12/24 (木) | 1/7 (木) |
| 資源 金 | 12/25 (金) | 1/8 (金) |

資源の年末最終日が 12/22〜25 と早い。**12/29 は火金コースの可燃の収集日**であって
休止日ではない。「年末年始は全部休み」と思い込むと誤る。

### 3. 特別収集日 — 祝日だが収集する

2 週連続で祝日になり通常収集ができない場合、市は振替日を設ける。
2026 年度は**水コースの 5/6** (4/29 と 5/6 がどちらも祝日) がこれに当たる。
祝日休止の計算からこの日を除外する。

## 使い方

```sh
node fetch.mjs                              # CSV 2 本と PDF を cache/ へ
EXTRACTED_AT=$(date +%F) node build.mjs     # course-*.yaml を生成
```

`pdftotext` (poppler) が要る。

## 実装メモ

- **コース番号は `sources.mjs` の `COURSE_IDS` で固定する。** 下流は `metadata.course` で
  識別するので、CSV の出現順に振り直すと URL も購読も壊れる
- **町は読み仮名の昇順**に並べる。CSV の掲載順ではない。比較はコードポイント順
  (`localeCompare` は濁点の扱いが環境で変わりうる)。
  "さだつぎだんち" < "さだつぎちょう" が だ(U+3060) < ち(U+3061) で決まる
- **「廃食用油（天ぷら油）」は収録しない。** 正典 `categories.yaml` に該当が無く、
  同日収集の別品目にも寄せられない。語彙の追加は上流の判断なので勝手に増やさない
- 資源系 18 列が同じ曜日であることを**確かめてから**コースの代表曜日にする。
  食い違ったら throw (曜日ひとつで代表できないため)

## 検証

日付入りの資料が無いため、規則を展開して突き合わせる相手が存在しない。
代わりに一次ソースの改訂を検出することを 5 通りの改竄で確認している。

| 改竄 | 結果 |
|---|---|
| 1 町の可燃曜日を 月木 → 水土 | コース数が 5 になり build が throw |
| 可燃の表記を「毎週月・木」→「月木」 | `燃やすごみの表記が未対応` で throw |
| 資源系の 1 品目だけ別曜日に | `資源系の曜日が品目で食い違っている` で throw |
| 祝日 CSV から 2026/8/11 (火) を削る | course 1 の overrides が 7 → 6 に減る |
| 復元 | 生成物が元通り |

## 履歴

- 2026-07 収録。CSV を人が読んで転記した。生成器は無く、`make regen` が skip し続けて
  いたため誤りを機械が検出できなかった
- 2026-08-21 生成器を起こした。**日程は 1 日も変えていない** — 旧データと
  1460 日枠 (4 コース × 365 日) で全日照合し不一致 0。areas も順序と読み仮名を含めて完全一致。
  祝日 (資源のみ休止)・年末年始 (品目別)・特別収集日 (5/6) がすべて機械で再現できた
