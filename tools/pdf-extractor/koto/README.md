```
node fetch.mjs                           # cache/ に配布シート 3 版 + CSV + ABR を揃える

node verify.mjs                          # 版どうし + 日本語版目視 + 展開の突合
```

## ソースの役割分担

| | 中身 | 役割 |
|---|---|---|
| 配布シート 多言語版 (`8ch.pdf` 中/`8ko.pdf` 韓) | 12 地区の曜日規則 + **燃やさないごみの隔週実日付 12か月** | **一次ソース** |

日本語版は画像 PDF、裏面は CID フォント化けで読めない。**テキスト層を持つのは多言語版だけ**
(豊島区と同じ構図)。ただし多言語版の町名は簡体字・ハングル表記なので、
**日本語の町名は CSV から取る**。

### CSV は地区割の正典ではない

現行版シートと 2 町で食い違う (豊洲・塩浜)。**逆方向の食い違いが 2 件**あり、
CKAN の `last_modified` は 2024-11-30、シートは令和8年度版。詳細と裁定の根拠は
`municipalities/tokyo/koto/meta.yaml`。`sources.mjs` の `DISTRICT_OVERRIDES` が置換表で、
build は置換対象の CSV 行が実在することを毎回確認する (消えていれば CSV が更新された合図)。

## 踏んだ罠

| 罠 | 何が起きたか | 対処 |
|---|---|---|
| **数字と単位が別の語** | 月ヘッダは "4" "月"、日付は "6" "日" が別々に出る。数字の中心だけで列に寄せたら隣の月へ流れ込み、**全 12 地区で曜日ずれと 11/13/15/17 日の間隔**が出た | 数字と単位を組にし、**合成スパンの中心**で寄せる |
| **連結と分かち書きの混在** | 韓国語版は 4〜9 月が "4월" (1 語)、10〜3 月が "10 월" (2 語) | 両方の形を受ける |
| **単位の字が版内で揺れる** | 韓国語版の 1 か所だけ単位が漢字の「月」 | 単位を集合で持つ (`{'월','月'}`) |
| **数字と単位の top がずれる** | 韓国語版は数字が単位より 4pt 下 | 許容を 6pt に |
| **ページ外に別レイヤーがある** | 韓国語版は x が負の領域に日本語のレイヤーが潜んでおり、月ヘッダが 3 倍に増えた | **ページ矩形の外の語を落とす** |
| **アンカー相対の x 窓が版で崩れる** | 韓国語版はブロックがアンカーより左に広く、中国語版と同じ窓では 1 列目を落とす | 月ヘッダを**行ごとに 3 ブロック × 6 列へ割る** (窓を使わない) |
| **複数曜日が 1 語** | "周二、周五" / "수ㆍ토" は 1 語で出る | 区切りで割ってから引く |

## 検査

`build.mjs` が毎回やること。

- 都カタログ CSV との曜日規則照合 (55 行 × 4 品目)。**CSV の鮮度検査を兼ねる** — 中野区の OD は 2021 年止まりだった
- 置換対象の CSV 行が実在するか (消えていれば CSV が更新された)
- ABR 町字 158 件をちょうど被覆するか (CSV が町名だけで書く町は ABR の丁目へ展開)
- 隔週の日付が 14 日刻みで、外れるのが年末年始の分だけか
- 自己検証: 生成 rules の再展開が抽出結果と全日一致 (4,308 日枠)

`verify.mjs` の 3 系統。

| | 何と何を比べるか | 規模 |
|---|---|---|
| A. 版どうし | 中国語版 ↔ 韓国語版 | 344 項目 |
| B. 日本語版 | 目視転記 ↔ 生成物 | 48 セル + 48 日付 |
| C. 展開 | 生成物の全日展開 ↔ 抽出結果 | 4,308 日枠 |

**B の日付は 12 月・1 月に絞ってある** — 年末年始の端で、12 地区中 5 地区がこの 2 か月で
1 回抜ける。抜けの有無がそのまま検査になる (playbook §6「サンプルは端を狙う」)。

`node verify.mjs --tamper` は 5 通りの改竄で各検査が落ちることを確かめる。
**うち 1 通りは当初空振りした** — 検査 C が生成物の出した収集日だけを回していたため、
生成物から日付を消すとループが訪れなかった。収録期間の全日を回す形に直してある。

## 次の版で気をつけること

- **年末年始の告知**が出たら `unknown_periods` を外して休止日を `overrides` に入れる。
- **発泡トレイがどのストリームに乗っているか**を確認する。台東区は令和7年3月末に
  食品発泡トレイを資源からプラスチックへ移した。曜日だけ見ていると気づけない。
- 都カタログ CSV との食い違い (豊洲・塩浜) が解消されたか確認する。解消されていれば
  `DISTRICT_OVERRIDES` を空にできる。
- シートの URL は `8ch.pdf` / `8omote.pdf` と年度トークンを含まないので変わりにくいが、
  内容は毎年差し替わる。`index.html` から辿り直す。
