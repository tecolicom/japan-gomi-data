
`meta.yaml` / `taxonomy.yaml` は**生成しない**。手書きが正典。

## なぜこの PDF が一次ソースなのか

豊島区は同じ曜日一覧を 2 系統で出している。

| | 中身 | 機械可読性 |
|---|---|---|
| 保存版冊子 p34-35「資源回収・ごみ収集曜日一覧(50音順)」 | 通常地域 43 行 + 繁華街地域 15 行 | **不可**。Microsoft Print To PDF 製で pdfplumber の `chars` が 0 |
| 外国語版リーフレット「資源回収・ごみ収集のお知らせ」と「曜日一覧」p2 | 同じ 58 行 | **可**。テキスト層あり。町丁名も曜日も日本語のまま |

外国語版は分別ルールの解説書ではなく、**2 ページ目が曜日表そのもの**である。
`survey.yaml` (2026-07-18) はこれを「町名別曜日表は含まず=照合力弱い」と書いていたが誤り
(→ `municipalities/tokyo/toshima/meta.yaml` に訂正を記録)。

外国語版は 6 言語 (英中韓 / ベトナム / ミャンマー / ネパール / タイ / ヒンディー) あり、
**同じ表を 6 通りに組版してある**。これを照合に使う。

## extract.py — 版面の座標を決め打ちしない

6 言語版を同じコードで読むため、拠り所は次の 3 つだけにしてある。

1. 町丁名も曜日も日本語のまま印字される (訳はその右に並ぶ)
2. 曜日セルは `火` / `月・木` / `第1・3金` のいずれかの形をしている
3. 「池袋駅周辺繁華街地域」の見出しから下が繁華街地域の表

### 踏んだ罠

| 罠 | 何が起きたか | 対処 |
|---|---|---|
| 行を上から畳んで区切れない | 英中韓版は 1 行が「日本語+英語」と「中国語+韓国語」の 2 段に分かれて印字され、その 2 段が隣のレコードとの隙間を埋める。素朴に畳むと 1 レコードに曜日セルが 112 個入った | **曜日セル行を錨にする**。4 つ揃った行が 1 レコード |
| 固定の許容幅が版ごとに壊れる | 折り返した町丁名を「曜日セル行から 5.2pt 以内」で拾っていたら、行間の広いミャンマー語版で日本語名を取り落とした | **隣の曜日セル行との中点**で受け持ち範囲を決める。表の端は隣との間隔の半分だけ外へ伸ばす |
| 「左端の行が日本語名」ではない | 訳文だけの行が日本語名より上に来たり (英中韓版の西池袋5丁目)、訳文の折り返しが日本語名より左に出たり (ミャンマー語版) する | 先頭語は**読み順で最初に現れる漢字・かなの連続**。訳文に漢字は無い |
| 日本語名と英訳が字間なしで隣接する | `池袋2丁目…19番（要` と `14-5,14-8,…` が隙間 0 で繋がる。数字は日英とも半角なので文字種でも切れない | 一次ソースだけ `--name-x-max 119.5` で x 帯を切る。他言語版では名前を読まない (照合には先頭語と曜日セルしか要らない) |

## 検査

`build.mjs` が毎回やること。

- **丁目の網羅** — 表の丁目が ABR 町字マスターの 83 件をちょうど過不足なく覆うか。
  区の刊行物の外から数を持ってくる唯一の検査なので効きが強い。行を落とせば足りなくなり、
  二重に読めば余る。
- **番地の重なり** — 同一丁目を分け合う行の番地が、**どちらにも限定 (号・通り沿い) が無いのに**
  重なっていないか。号や「(要町通り沿い以外)」で正当に重なる番が 7 組あるので、
  括弧を落として番だけ見ると全部が偽陽性になる。
- **番地として読めない断片** — 一次ソースの表記ゆれ・誤記がここに出る。
  2026-08-31 時点で 1 件 (`6号18番`。簡易版で読点が落ちている。詳細は meta.yaml)。
- **自己検証** — 生成した rules を `expandRange()` で展開し直し、曜日セルの文字列から
  直に計算した結果と全日突き合わせる。合わなければ書き出さない。

`verify.mjs` の 3 系統。

| | 何と何を比べるか | 規模 | 独立性 |
|---|---|---|---|
| A. 版どうし | 一次ソース ↔ 外国語版 5 種 | 5 版 × 58 行 | 弱 (同じリーフレット群。版面の読み違いは検出できる) |
| B. 内部 | 日本語セル ↔ 英語セル | 232 セル | 弱 (同一 PDF。ただし翻訳工程は別) |
| C. 保存版 | 目視転記 58 行 ↔ 生成物を全日展開 | 102 area × 244 日 | **強** (別の刊行物・別の版面) |

C の目視転記は `BOOKLET_ROWS` に固定保持している (一過性にしない)。
保存版と簡易版は句読点が揺れる (`34番(14号～20号)` / `34番（14～20号）`) ので、
照合キーは区切り記号を落として比べる。

`node verify.mjs --tamper` は 5 通りの改竄で各検査が落ちることを確かめる。
消す方向 (曜日をずらす・行を削る) と足す方向 (第n を増やす) の両方を含む。
