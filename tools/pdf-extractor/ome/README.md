# 青梅市 資源物・ごみ収集カレンダー抽出 (pdf-extractor/ome)

青梅市「令和8年度版 資源物・ごみ収集カレンダー」(2026年4月〜2027年3月) の**日程別 PDF** から
`municipalities/tokyo/ome/` の course/meta/taxonomy を生成するパイプライン。

## 一次ソース

- 案内ページ: https://www.city.ome.tokyo.jp/soshiki/23/1182.html
- 日程別 PDF (A〜H日程): `https://www.city.ome.tokyo.jp/uploaded/attachment/<ID>.pdf`
  - **市サイトは同じ内容の PDF を町名ごとに別の attachment ID で貼っている** (A日程だけで 13 ID)。
    日程ごとに 1 本を代表として取得し、別 ID が byte 単位で同一であることを
    `node fetch.mjs --check-dup` の sha256 比較で確認済み。
  - 代表 ID: A=77610 / B=77621 / C=77611 / D=77615 / E=77665 / F=77667 / G=77617 / H=77679

### ライセンス

ライセンス明示なしの通常ページ。市のオープンデータに収集日程データセットは無いため、
**収集日という事実データを抽出**して収録する (練馬・杉並・調布と同じ整理)。

## サーベイの訂正

2026-07-18 のサーベイは「カレンダーは画像グリッドで pdftotext では取得不可、difficulty 4」と
記録していたが、実際には**罫線が本物のベクタ線**でグリッドを座標復元でき、
品目も**塗り色で判定できる**。survey.yaml は difficulty 2 / granularity dates へ訂正した。

## パイプライン

```
node fetch.mjs [--check-dup]           # index.html + 日程別 PDF 8 本を cache/ へ
node fetch-yomi.mjs                    # ABR 町字マスター(pref13)から青梅市149町字を cache/abr-town.json へ
python3 extract.py                     # カレンダーPDF → cache/extracted.json (日程 × 日付 → 品目)
EXTRACTED_AT=YYYY-MM-DD node build.mjs # extracted.json → course-{A..H}.yaml + meta.yaml + taxonomy.yaml
node verify.mjs                        # 再展開照合 + 冊子本文の頻度規則照合 + PDF画像の目視照合
```

`extract.py` は `pdfplumber` を使う (`pip install pdfplumber`)。8 本ぶんで数分かかる。

## PDF の構造 (extract.py)

28 ページの冊子で、**20〜25 ページが日付入りの通年カレンダー** (1 ページに 2 ヶ月ブロック = 12 ヶ月)。

- カレンダーページの判定は**曜日ヘッダ (SUN..SAT) が 2 ブロック分あること**。
  罫線の数だけで判定すると分別一覧などの表ページを拾ってしまう。
- ブロック矩形 = 長い水平罫線 (length>200) の x 範囲 (左 `[19.0, 400.2]` / 右 `[441.6, 822.8]`)。
- 列境界 = 長い垂直罫線 6 本 + ブロック左右端 → 7 列。**列幅は不均等**で、資源物のラベルが
  並ぶ曜日の列だけ極端に広い (A日程なら水曜が 122pt、日曜は 25pt)。
- 行境界 = 長い水平罫線 5 本 + 垂直罫線の bottom → 5 行。
- 日付は**グリッド位置から計算**する (その月 1 日の直前の日曜を起点に `行×7+列`)。
  印字された日番号がそれと一致することを検査する。6 週ある月は 1 セルに 2 つ縦積みされるので、
  「そのセルの日付」か「その 7 日後」のどちらかを採る。
- 前月末・翌月頭の日 (灰色) もセルに入るが品目は付かない。月外へ帰属した品目は throw する。

### 品目はテキストではなく色で取る

**品目名はすべてアウトライン化された図版**で、テキスト層には日番号・曜日ヘッダ・西暦しか無い。
そこで秩父広域と同じ**色ベース抽出**を使う。文字も日付も読まない。

| 図版 | 寸法 | 品目 (塗り色) |
|---|---|---|
| 袋アイコン | 40×35 | 燃やすごみ (緑) / 容器包装プラスチックごみ (紫) / 燃やさないごみ (橙) |
| 角丸ラベル | 32〜33×20 | ペットボトル (黄) / 有害ごみ (桃) / カン / ガラス / ビン / 陶磁器 |
| 角丸ラベル | 43×20 | 繊維類 |
| 角丸ラベル | 68×20 または 43×44 (3行組) | 新聞・折込チラシ / 雑誌・雑紙 / ダンボール・飲料用紙パック |

- 3 行組 (43×44) は B・C・E・F・G日程で使われる。**雑誌・雑紙とダンボールは 1 行組と 3 行組で
  塗り色が微妙に違う**ため、色と寸法の組で対応表を持つ。
- 未知の色は無視される。市が配色を変えると静かに壊れるので、
  **次年度の収録時は `extract.py` が出す品目別件数を必ず確認すること**。

## 収集頻度 (冊子本文の明記どおり)

| 品目 | 頻度 |
|---|---|
| 燃やすごみ | 週2回 |
| ペットボトル / 有害ごみ | 週1回 (同日) |
| 容器包装プラスチックごみ | 資源日のうち燃やさないごみの回を除く (月3〜4回) |
| 燃やさないごみ | 月1回 (3回目) |
| 新聞・折込チラシ | 月1回 (1回目) |
| 雑誌・雑紙 | 月1回 (2回目) |
| ダンボール・飲料用紙パック | 月1回 (3回目) |
| 繊維類 | 月1回 (4回目) |
| カン / ガラス | 月2〜3回 (1・3・5回目、同日) |
| ビン / 陶磁器 | 月2回 (2・4回目、同日) |

祝日も通常どおり収集する。年末年始 (12月末〜1月3日ごろ) のみ休止で、日程ごとに実日付が異なる。
H日程 (御岳山) は山間で頻度が低く、燃やすごみも週1回。

資源物はすべて `monthly_specific` (実日付列挙) にした。規則自体は「月内の n 回目のその曜日」だが、
年末年始の休止でひと月ぶん周期がずれる日程があり (E・F・H日程の2027年1月など) `monthly_nth` では表せない。

## 種別マッピング

| カレンダー表記 | category |
|---|---|
| 燃やすごみ | burnable |
| 燃やさないごみ | non_burnable |
| 容器包装プラスチックごみ | plastic |
| 新聞・折込チラシ / 雑誌・雑紙 / ダンボール・飲料用紙パック | paper (内訳は rule の note) |
| 繊維類 | cloth |
| ビン | glass_bottle |
| カン | beverage_can |
| ペットボトル | pet_bottle |
| 有害ごみ | hazardous |
| **ガラス** (びん以外のガラス製品) | — カンと常に同日のため未収録 |
| **陶磁器** | — ビンと常に同日のため未収録 |

ガラス・陶磁器は正典 `schema/categories.yaml` に該当語彙が無い。いずれもカン・ビンと
**常に同日収集**なので日程情報の欠落はゼロ (鯖江の廃食用油・西東京の同型)。
同日性は verify.mjs が全日程で機械確認する。

## areas

44町149町字。丁目のある町は **1 area = 1 丁目**、大字のみの行も別 area として残す (playbook の規約)。

- 町名→日程の対応は index ページの表 (町名セル + 「…カレンダーＸ日程」リンク) を一次とする。
- yomi / machiaza_id は ABR 町字マスター東京都版 (`lg_code=132055`) 由来。
- build は 8 日程の割当が ABR の全 149 町字を**重複・欠落なく分割する**ことを検査する。

## 照合 (verify.mjs)

1. 生成済み course YAML を再展開 → `extracted.json` と全 2920 日枠を比較。
2. **冊子本文の頻度規則**(「収集は月1回(第3週目)です」等、色とは独立に人が書いた表現)を
   機械パースして突き合わせる (8日程×13枠=104枠)。同日性・排他性も検査する。
   年末年始で周期がずれる 日程×月 は判定から外し、外した先を一覧出力する。
3. **PDF ページ画像の目視転記**との照合 (A・B日程の2026年4月・5月、86日枠)。
