# 毛呂山町 (埼玉県入間郡) ごみ・資源収集日 抽出

- **handle**: `moroyama-town` / **code**: 11326 / **収録**: 3 コース (A/B/C地区)
- **一次ソース**: 埼玉西部環境保全組合(毛呂山町のごみ処理を担う一部事務組合)の令和8年度カレンダーPDF
  `http://www.hozenkumiai.or.jp/pdf/moroyama2026_{a,b,c}.pdf` (日付入りカレンダー、テキスト層あり)
- 町公式サイトの同名PDFはベクター描画でテキスト層が無く不採用

## 実行手順

```
node fetch.mjs        # 組合カレンダーPDF a/b/c を cache/ へ
python3 extract.py    # pdfplumber で日付グリッドを座標抽出 → cache/records.json (地区×日付→品目)
EXTRACTED_AT=YYYY-MM-DD node build.mjs   # パターン導出して municipalities/saitama/moroyama-town/2026/ を生成
```

## 収集体系 (正典カテゴリ)

- 可燃 = `burnable` / 不燃 = `non_burnable` / 他プラ(その他容器包装プラ) = `plastic`
- びん缶(びん・かん類 同日) = `glass_bottle` + `beverage_can`
- 有害 = `hazardous` / 紙布(紙・布類 同日) = `paper` + `cloth` / ペット = `pet_bottle`

## 抽出のしくみ

**extract.py** — 1ページに12ヶ月(3列4段)。段(top)×固定列(842÷3)で月ブロックを切り、各月グリッドの
日付数字の直下(同じ曜日列・48pt以内)にある品目略称を対応づける。割当は **x差(曜日列)を優先**し、
同x差なら top 最近(隣接曜日への誤配置を防ぐ)。紙・布類は「紙」「布」の2 word で入るため「紙」で代表。

**build.mjs** — 各品目の実収集日から曜日+第n パターンを導出:
- ある曜日が第1〜5をほぼ揃える(≥4種) → `weekly`
- 特定の第n のみ → `monthly_nth`
- 出現8回未満の少数曜日は抽出ノイズとして除外

パターンで令和8年度の全収集日を再生成し、実日付と突合。パターンにあり実に無い日(年末年始休止)は
`overrides` に cancelled 記録、実にあってパターンに無い日は 0 件(完全再現)。

## 地区について

収集は A/B/C の3地区で、地区ごとに曜日が異なる(例 可燃: A=月木 / B=火金 / C=火金、他品目も相違)。
地区に含まれる町名・大字の対応表は町・組合とも非公開(カレンダーPDF内の地図のみ)のため、areas は
地区名のみとした。住民は配布された自地区のカレンダーで判断する。

## 検証

build.mjs のパターン再展開↔実日付の突合が自己検証を兼ねる(倉敷と同型)。3地区とも実にあってパターンに
無い日 0 件、逸脱は年末年始休止のみ。日付入り年間カレンダーが一次ソースなので日付レベルまで一致。
