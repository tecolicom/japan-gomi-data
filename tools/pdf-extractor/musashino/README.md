# 武蔵野市 ごみ収集カレンダー抽出 (pdf-extractor/musashino)

武蔵野市「【令和8年度(2026年度)版】ごみと資源の収集カレンダー」の**地区別 PDF**
(日付入り通年カレンダー) から `municipalities/tokyo/musashino/` の course/meta/taxonomy を
生成するパイプライン。

## 一次ソース

- 案内ページ: https://www.city.musashino.lg.jp/gomi_kankyo/gomi/gomi_shushubi/1053782.html
- 収集カレンダー (A〜J地区): `.../001/053/782/2026{a..j}-1.pdf`
  **※ C と E だけ `2026c-1-1.pdf` / `2026e-1-1.pdf`** (市側の差し替えの名残)
- 収集日一覧表 (参考): `.../2026{a..j}-2.pdf` / 集合住宅用: `sticker2026{a..j}.pdf`
- 共通 (分別ルール): `.../2026kyoutuu.pdf`
- **収録期間 2026年4月〜2027年3月** (ちょうど令和8年度)。

### ライセンス

市サイトは CC 宣言なし。収集日という事実データを抽出して収録する
(練馬・杉並・調布と同じ整理)。

## パイプライン

```
node fetch.mjs                         # index.html + カレンダー/一覧表 PDF 20 本を cache/ へ
node fetch-yomi.mjs                    # ABR 町字マスター(pref13)から武蔵野市51町字を cache/abr-town.json へ
python3 extract.py                     # カレンダーPDF → cache/extracted.json (地区 × 日付 → 品目)
EXTRACTED_AT=YYYY-MM-DD node build.mjs # extracted.json → course-{A..J}.yaml + meta.yaml + taxonomy.yaml
node verify.mjs                        # 再展開照合 + 市サイト曜日サマリ照合 + PDF画像の目視照合
```

`extract.py` は `pdfplumber` を使う (`pip install pdfplumber`)。

## PDF の構造 (extract.py)

Illustrator 製 A4 横 7 ページ。**1 ページ目は表紙**(前年度のミニ暦を含む)で、
2〜7 ページに各 2 ヶ月ブロック (左/右) が入り計 12 ヶ月。
**本物の罫線ベクタ**が入っているので、色ベース抽出 (秩父広域) は不要で座標グリッドを復元できる。

| 要素 | 取り方 | 実測値 |
|---|---|---|
| ブロック矩形 | 長い水平罫線 (length>300) の x 範囲 | 左 `[23.0, 415.6]` / 右 `[426.3, 818.9]` |
| 列境界 | 長い垂直罫線 (length>300) 6 本 + ブロック左右端 → 7 列 (日〜土) | 左 `45.6 / 115.1 / 184.5 / 254.0 / 323.4 / 392.9` |
| グリッド天地 | 長い垂直罫線の top/bottom | `88.2 〜 547.4` (これより下はフッター) |
| 月と年 | ヘッダの英語月名 (`April` 等) と 4 桁西暦 | ページ順ではなくこれで判定 |

### 罠と対処

1. **太字の文字二重打ち** — `燃燃ややすす` → `燃やす`。偶数長かつ `s[i]==s[i+1]` (i 偶数) なら
   1 文字おきに取る。品目だけでなく注記 (`注注意意`) や添え書きにも起きる。
2. **ページ番号を日番号と誤認する** — ページ番号は 8pt。日番号は 12.8pt (土日) / 21.0pt (平日)
   なので `size >= 10` で分離できる。
3. **6 週ある月は物理行が 5 行しかない** — あふれた週末日が同じセルに縦積みされる
   (2026年8月は 8/1(土) の下に 8/8、2026年5月は第5行の日セル下部に 5/31)。
   行バンドで機械的に切らず、**「同じ列で自分より上にある直近の日番号」**に品目を帰属させる。
4. **列は語の中心で判定する** — 左端 (x0) で判定すると、セル内で中央寄せされた添え書き
   「(年末特別収集)」が隣の列にはみ出して 1 日ずれる (12/29 → 12/28 の誤り。実際に踏んだ)。
5. `pdftotext -layout` は列がずれる (火曜の品目が水曜に見える)。**必ず座標で取ること**。
6. グリッド内には品目以外の語 (バナー「7月からペットボトルの毎週収集が始まります!」、
   注記「年が明けてもカレンダーを捨てないでください。」等) も入る。全 PDF を走査して
   洗い出した閉集合を `IGNORE` に持ち、**それ以外の未知語は throw** する (握りつぶし禁止)。

`extract.py` は各月について「日番号が 1〜月末日まで欠落・重複なく現れること」と
「列(曜日)が実曜日と一致すること」を検査する。これがグリッド復元の一番強い保証になっている。

## 抽出ロジック (build.mjs)

品目ごとに収集日を集計して自動分類する:

- **weekly (+ cancelled override)** — 燃やすごみ (週2)、古紙、古着 (週1)、
  プラスチック製容器包装 (週1)。年末年始の停止だけが例外。
- **monthly_specific** — 燃やさないごみ / びん・缶・危険有害ごみ (いずれも隔週)、
  およびペットボトル (**6月まで隔週・7月から毎週**で年度途中に頻度が変わる)。

隔週の品目はその曜日に「収集がある週」と「何も無い週」が交互に来るため、
素朴に「毎週 + 半分を cancelled」と表現できてしまう。これを避けるため、
weekly と認めるのは**停止で欠ける回数が全体の 10% 以下**のときだけにしている
(`WEEKLY_STOP_TOLERANCE`)。

分類後 `expandRange()` で収録期間 (365日) を再展開し、PDF から読んだ実日付と
**完全一致**することを build 内で自己検証する (不一致なら書き出さない)。

## 種別マッピング

| カレンダー表記 | category |
|---|---|
| 燃やす (燃やすごみ) | burnable |
| 燃やさない (燃やさないごみ) | non_burnable |
| プラスチック製 + 容器包装 (2 語で 1 品目) | plastic |
| 古紙・古着 | paper_cloth |
| ペットボトル | pet_bottle |
| びん | glass_bottle |
| 缶 | beverage_can |
| 危険有害 | hazardous |

粗大ごみは予約制のため rules の対象外。

## 運用ルール

- 戸別収集。収集日の朝 9 時までに敷地内の決められた場所へ。
- **祝日・振替休日も通常どおり収集**。土曜・日曜と年末年始は収集しない。
- 年末年始の休止日は地区で異なる (A〜E: 12/29〜1/1、F〜J: 12/30〜1/1)。
  F〜J地区は 12/29 の燃やすごみに「(年末特別収集)」の添え書きがあり、course の rule note に残した。

## areas

13町51丁目。**1 area = 1 丁目**に展開する (playbook の規約)。

- 地区→町名の対応は index ページ本文の「A地区 吉祥寺南町」等を一次とし、
  丁目の実在・読み・町字IDは ABR 町字マスター東京都版 (`lg_code=132039`) から引く。
- 丁目で割れるのは **吉祥寺本町** (1丁目=C地区 / 2・3・4丁目=B地区) のみ。
- build は 10 地区の割当が ABR の全 51 町字を**重複・欠落なく分割する**ことを検査する。

## 照合 (verify.mjs)

1. 生成済み course YAML を再展開 → `extracted.json` と全 3650 日枠を比較。
2. **市サイトの地区別曜日サマリ**(PDF とは別に人が書いた表現)を機械パースし、
   10地区×5曜日=50 枠の「曜日→品目集合 + 毎週/隔週の別」と突き合わせる。
   判定窓はペット毎週化後・年末年始の手前 (2026-07-06〜2026-12-25)。
3. **PDF ページ画像の目視転記**との照合 (6ヶ月130日枠)。6週ある月 (2026年8月・5月) と
   年末年始 (2026年12月・2027年1月) を狙って選んである。
